# تحديثات يلا دليفيري لأندرويد خارج Google Play

## تجهيز السيرفر

انشر تغييرات الـ backend ولوحة الإدارة، وشغّل migrations ضمن مسار النشر المعتاد.
الترحيل `dashboard/0006_deliveryapprelease` يضيف سجل إصدارات التطبيق.
أعد إنشاء خدمة Nginx بإعدادات النشر المعتادة لتفعيل حد رفع APK المخصص؛
الحد الافتراضي لبقية الطلبات يظل 8 MB، وملف APK الواحد لا يتجاوز 100,000,000 بايت.
ملفات APK تحفظ في التخزين العام الحالي تحت `app-updates/delivery/` بأسماء فريدة،
سواء كان التخزين المحلي المستمر أو S3. لا ترفع ملفات المفاتيح أو كلمات مرور التوقيع.

## تجهيز أول نسخة

أول APK يوزع على المستخدمين يجب أن يحتوي على تنفيذ التحديث الجديد نفسه.
أنشئ إصدار release بإعدادات HTTPS والتوقيع الحالية للمشروع. احتفظ بنفس
`applicationId` ومفتاح توقيع release في كل الإصدارات اللاحقة.
أرقام البناء في الأمثلة توضيحية؛ راجع `yalla_delivery/pubspec.yaml` قبل كل بناء.

مثال لبناء التحديث التالي، مع استبدال عنوان API بعنوان السيرفر الحقيقي:

```powershell
flutter build apk --release --build-name=1.0.12 --build-number=4016 --dart-define=API_BASE_URL=https://api.YOUR-DOMAIN/api/v1
```

الملف الناتج: `yalla_delivery/build/app/outputs/flutter-apk/app-release.apk`.
بناء release الحالي يستهدف arm64-v8a وفق إعداد المشروع.

## نشر كل تحديث

1. من قائمة الحساب أسفل القائمة الجانبية في لوحة الإدارة افتح «تحديثات التطبيق» (`/app-updates`).
2. أدخل اسم الإصدار ورقم البناء المطابقين للـ APK. رقم البناء يجب أن يزيد عن النسخ المثبّتة.
3. أضف وصفًا مختصرًا للتحسينات، واختر APK ثم اضغط «رفع ونشر التحديث».
4. بعد اكتمال الرفع يظهر الإصدار في السجل مع رابط تحميل يمكن استخدامه لأول تثبيت أيضًا.
5. يمكن إيقاف نشر إصدار لمنع عرضه كتحديث جديد. هذا لا يلغي تنزيلًا بدأ بالفعل ولا يعيد الأجهزة لإصدار أقدم.

التطبيق يفحص عند الفتح وعند العودة بعد 15 دقيقة، ويمكن الفحص يدويًا من الملف الشخصي.
«لاحقًا» يغلق النافذة ويترك شريط التحديث متاحًا. «تحميل الآن» يبدأ تنزيلًا
يديره Android DownloadManager ويستمر في الخلفية. بعد التنزيل والتحقق من SHA-256
وهوية الحزمة ورقم البناء وتوقيعها يظهر إشعار «اضغط لتثبيت التحديث» وزر تثبيت داخل التطبيق.
المستخدم يوافق على التثبيت، وعلى السماح بالتثبيت من يلا دليفيري عند طلب أندرويد.
إذا رفض الإشعارات يظل التحميل وزر التثبيت داخل التطبيق متاحين.

لا يتم تثبيت أي ملف تلقائيًا، ولا يتم إرسال رمز تسجيل دخول مع رابط تنزيل APK العام.
النشر محمي بصلاحيات الأدمن، وفحص أحدث إصدار متاح بدون تسجيل دخول حتى يعمل قبل شاشة الدخول.

## فحص جهاز قبل التوزيع

ثبّت إصدار release أولًا، ثم ارفع APK أحدث بنفس المفتاح. جرّب التحميل بالخلفية،
إغلاق التطبيق وفتحه، الضغط على إشعار الاكتمال، منح/رفض إذن التثبيت، ثم التحديث
والتأكد من بقاء تسجيل الدخول والبيانات. جرّب أيضًا انقطاع الشبكة ورفض الإشعارات.
لا تستخدم APK debug لتحديث نسخة release لأن مفتاح التوقيع مختلف.
